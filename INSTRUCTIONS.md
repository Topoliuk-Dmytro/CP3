# Інструкції з використання

## Встановлення залежностей

### Python
```bash
pip install -r requirements.txt
```
або
```bash
pip install numpy
```

### Julia
Julia не потребує додаткового встановлення пакетів, оскільки використовує стандартні модулі `Random` та `LinearAlgebra`, які входять до базової установки.

## Запуск програм

### Python
```bash
python matrix_determinant_python.py
```

### Julia
```bash
julia matrix_determinant_julia.jl
```

## Очікуваний вивід

### Python
- Згенерована матриця 4x4
- Значення визначника
- Час виконання в мілісекундах
- Використання пам'яті (поточне та пікове)
- Версії Python та NumPy

### Julia
- Згенерована матриця 4x4
- Значення визначника
- Час виконання в мілісекундах
- Виділена пам'ять в кілобайтах
- Версія Julia

## Примітки

1. Для отримання більш точних результатів продуктивності рекомендовано запускати програми кілька разів та брати середнє значення.

2. Результати можуть відрізнятися залежно від:
   - Апаратного забезпечення
   - Навантаження системи
   - Версій мов та бібліотек

3. Для детального аналізу продуктивності можна використати профілери:
   - Python: `cProfile`, `memory_profiler`
   - Julia: `@profile`, `@time`, `@allocated`
