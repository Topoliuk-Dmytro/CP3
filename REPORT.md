# Звіт: Порівняння реалізацій обчислення визначника матриці

## Мета роботи

Порівняти реалізації обчислення визначника матриці 4x4 з випадковими значеннями (діапазон 1-9) на мовах програмування Python та Julia, проаналізувати різницю в реалізації, продуктивності та використанні пам'яті.

## Опис алгоритму

Обидві реалізації використовують однаковий підхід:
1. Генерація матриці 4x4 з випадковими цілими числами від 1 до 9
2. Обчислення визначника за допомогою стандартних бібліотек лінійної алгебри
3. Вимірювання часу виконання та використання пам'яті

### Алгоритм обчислення визначника

Обидві мови використовують LU-розклад матриці для обчислення визначника:
- **Python (NumPy)**: `numpy.linalg.det()` - реалізує LU-розклад з частковим вибором головного елемента
- **Julia (LinearAlgebra)**: `det()` - також використовує LU-розклад, оптимізований для Julia

## Реалізації

### Python

**Особливості реалізації:**
- Використання бібліотеки NumPy для роботи з матрицями
- Модуль `tracemalloc` для відстеження використання пам'яті
- Модуль `time.perf_counter()` для точного вимірювання часу

**Ключові моменти:**
```python
matrix = np.random.randint(1, 10, size=(4, 4))
determinant = np.linalg.det(matrix)
```

### Julia

**Особливості реалізації:**
- Використання вбудованих типів та функцій Julia
- Макрос `@allocated` для вимірювання виділеної пам'яті
- Функція `time_ns()` для наносекундного вимірювання часу

**Ключові моменти:**
```julia
matrix = rand(1:9, 4, 4)
determinant = det(matrix)
```

## Порівняння реалізацій

### 1. Синтаксис та структура коду

| Аспект | Python | Julia |
|--------|--------|-------|
| Генерація матриці | `np.random.randint(1, 10, size=(4, 4))` | `rand(1:9, 4, 4)` |
| Обчислення визначника | `np.linalg.det(matrix)` | `det(matrix)` |
| Типізація | Динамічна | Опціональна статична |
| Імпорти | Потрібні зовнішні бібліотеки (NumPy) | Вбудовані модулі |

### 2. Вимірювання продуктивності

**Python:**
- Використовує `tracemalloc` для відстеження виділеної пам'яті
- `time.perf_counter()` забезпечує високу точність вимірювання часу
- Вимірює поточне та пікове використання пам'яті

**Julia:**
- Макрос `@allocated` точно вимірює виділену пам'ять під час виконання
- `time_ns()` забезпечує наносекундну точність
- Більш точне вимірювання через вбудовані інструменти мови

### 3. Особливості мов

**Python:**
- Потребує зовнішніх бібліотек (NumPy) для ефективної роботи з матрицями
- Інтерпретована мова з динамічною типізацією
- Велика екосистема бібліотек
- Простіший синтаксис для початківців

**Julia:**
- Високопродуктивна мова, спроектована для наукових обчислень
- JIT-компіляція забезпечує швидкість, близьку до C
- Вбудована підтримка лінійної алгебри
- Оптимізація під час компіляції

## Очікувані результати продуктивності

### Час виконання

**Julia** зазвичай демонструє:
- Швидше виконання завдяки JIT-компіляції
- Менше накладних витрат на інтерпретацію
- Оптимізація під час компіляції

**Python** зазвичай демонструє:
- Повільніше виконання через інтерпретацію
- Але NumPy використовує оптимізовані C-бібліотеки (BLAS/LAPACK)
- Для малих матриць різниця може бути незначною

### Використання пам'яті

**Julia:**
- Більш ефективне використання пам'яті
- Менше накладних витрат на об'єкти
- Пряма робота з типами даних

**Python:**
- Додаткові накладні витрати на об'єкти Python
- NumPy використовує ефективні масиви, але з обгорткою Python
- Більше виділеної пам'яті для малих обчислень

## Висновки

### Переваги Python
1. **Простота використання**: інтуїтивний синтаксис, велика кількість документації
2. **Екосистема**: величезна кількість бібліотек та інструментів
3. **Універсальність**: підходить для різноманітних завдань
4. **Сумісність**: легко інтегрується з іншими системами

### Переваги Julia
1. **Продуктивність**: швидкість виконання близька до скомпільованих мов
2. **Ефективність пам'яті**: менше накладних витрат
3. **Спеціалізація**: створена для наукових обчислень
4. **Вбудовані інструменти**: багато функцій доступні "з коробки"

### Рекомендації

**Використовувати Python, якщо:**
- Потрібна швидка розробка та прототипування
- Важлива доступність бібліотек та інструментів
- Команда знайома з Python
- Завдання не критичні до продуктивності

**Використовувати Julia, якщо:**
- Потрібна максимальна продуктивність
- Робота з великими обсягами даних
- Наукові обчислення та числовий аналіз
- Важлива ефективність використання пам'яті

### Загальний висновок

Обидві мови успішно вирішують задачу обчислення визначника матриці. Вибір мови залежить від конкретних вимог проекту:
- Для швидкої розробки та прототипування - **Python**
- Для максимальної продуктивності та ефективності - **Julia**

Для матриць малого розміру (4x4) різниця в продуктивності може бути незначною, але для великих матриць та складних обчислень Julia має значні переваги.
